# gender-and-crime
This project estimated the proportion of female offenders to male offenders using crime data from San Jose. I estimated and narrowed the underlying parameter of proportion of crimes that are done by women compared to men, and primarily employed Bayesian techniques to improve the estimate. My analysis contained three main methods to identify the best posterior that could have generated the data. Firstly, I explored a beta-binomial one-parameter Bayesian analysis. Next, I investigated hierarchical structures in the dataset, and finally, I tested a sequential Bayes method. Analysis.qmd contains the cleaning and merging of the datasets, EDA, and finally Bayesian analysis to estimate the parameter. The .stan files allowed for hyperparameter search on the prior with Markov Chain Monte Carlo. 

Data Source (Kaggle): https://www.kaggle.com/datasets/jsherman256/sjpd-incidents-arrests-charges?resource=download
